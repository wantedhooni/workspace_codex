# AGENTS

## 작업 목적
- Spring Cloud 기반 MSA 스캐폴딩 프로젝트를 구성한다.
- Spring Boot, Spring Data JPA, Querydsl 조합을 기본 표준으로 사용한다.
- 실무에서 바로 확장 가능한 멀티모듈 구조를 우선한다.

## 작업 원칙
- 현재 작업공간 안에서만 작업한다.
- 공통 규약, 예외 응답, 실행 방법을 문서로 남긴다.
- 서비스는 독립 실행 가능해야 하며, 로컬 개발 기준 설정을 포함한다.
- 예제 코드는 단순 데모가 아니라 확장 가능한 구조로 작성한다.

## 산출물 기준
- 루트 멀티모듈 Gradle 프로젝트
- discovery, gateway, domain service 모듈
- JPA + Querydsl 예제 구현
- 실행 및 확장 가이드 문서
