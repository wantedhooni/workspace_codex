Config Server UI

native config-repo와 Vault에서 읽은 설정을 한 화면에서 조회한다. Spring Cloud Config Server의 기본 HTTP API 위에 올린 조회용 UI다.

설정 조회 API:
/config/{application}/{profile}

Vault는 secret/<application> 또는 secret/application 경로를 기본으로 사용한다.

ready
Application과 Profile을 입력하면 설정 원본을 조회한다.
