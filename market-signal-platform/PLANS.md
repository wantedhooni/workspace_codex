# PLANS

## 목표
미국 주식 시장 상태, 섹터 강도, 종목 시그널, 뉴스 분석을 제공하는 웹 기반 투자 분석 플랫폼을 모노레포로 구축한다.

## 단계
1. 루트 문서와 디렉터리 구조를 준비한다.
2. Spring Boot 백엔드의 인증, 사용자, 관심종목 API를 구현한다.
3. 시장 엔진, 종목 시그널 엔진, 리포트, 뉴스 분석 API를 구현한다.
4. Next.js 프론트엔드의 인증 및 분석 UI를 구현한다.
5. Docker, 실행 스크립트, 테스트, README를 정리한다.

## 산출물
- 실행 가능한 백엔드 / 프론트엔드 코드
- PostgreSQL / Redis 연동 설정
- Docker Compose 기반 로컬 실행 환경
- 데모 계정과 샘플 데이터
- API 문서 및 아키텍처 설명
