# AGENTS

## 프로젝트 원칙
- 이 저장소는 미국 주식 시장 분석 플랫폼 전용 작업공간으로 사용한다.
- 구현은 실무 배포를 가정하고 계층 분리, 테스트, 실행 자동화를 우선한다.
- 백엔드는 Spring Boot 기반 모듈형 구조를 유지하고, 프론트엔드는 기능 단위로 분리한다.
- 설명 문서와 작업 기록은 한국어로 유지한다.

## 구현 규칙
- `backend`, `frontend`, `docker`, `scripts` 기준의 모노레포 구조를 유지한다.
- 클래스, 서비스, 서비스 메서드에는 한국어 Doc 주석을 작성한다.
- 인증은 JWT access token + refresh token 조합으로 구현한다.
- 데모 실행이 가능하도록 시드 데이터와 실행 스크립트를 제공한다.
- 작업 완료 후 `README.md`를 항상 최신 상태로 갱신한다.
