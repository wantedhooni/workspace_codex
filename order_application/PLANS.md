# 개발 계획

## 목표

주문/결제 계열 시스템을 확장 가능한 모노레포 형태로 초기 구성한다.

## 범위

- 백엔드
  - `api-admin`
  - `web-api`
  - `backend-common`
- 프론트엔드
  - `admin-app`
  - `web-app`

## 원칙

- 백엔드는 Spring Boot, JPA, Querydsl, JWT를 공통 기반으로 사용한다.
- 프론트엔드는 React, Next.js 기반 워크스페이스로 구성한다.
- Saga 오케스트레이터는 도입하지 않고, 멱등성/Unknown/Outbox 중심 설계를 유지한다.
- 초기 단계부터 상태 enum, 운영용 상태 조회, 확장 가능한 패키지 구조를 잡는다.

## 작업 순서

1. 저장소 루트 문서와 모노레포 디렉터리 구조를 만든다.
2. Gradle 멀티모듈 백엔드 프로젝트를 구성한다.
3. 주문/결제/Outbox 확장을 위한 공통 도메인 골격을 추가한다.
4. JWT 보안, JPA, Querydsl 설정을 공통화한다.
5. Next.js 워크스페이스와 앱 2종을 구성한다.
6. 빌드와 기본 실행이 가능한지 검증한다.
