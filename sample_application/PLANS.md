# 개발 계획

## 1. 아키텍처
- 단일 저장소 내 `backend`, `frontend` 분리
- 백엔드 내부 도메인 패키지 분리
  - channel: 신청/고객 접점, 멱등 처리
  - account: 원장/잔액/계약, 트랜잭션 확정
  - information: 확정 이벤트 적재/조회
  - external: 대외 전문 송수신/재전송

## 2. 백엔드 구현 계획
- Spring Boot 3.x + Java 21 + JPA + Querydsl 설정
- H2 기반 로컬 실행 환경
- 계좌 개설, 입출금, 원장 기록, 이벤트 적재 API 구현
- 대외 전문 생성/재전송 API 구현

## 3. 프론트엔드 구현 계획
- Next.js(App Router) 기반 대시보드
- 도메인별 페이지 제공(채널/계정/정보/대외)
- 백엔드 REST API 연동

## 4. 검증
- 백엔드 빌드/실행 확인
- 프론트엔드 타입체크/린트 가능한 구조 확인
