# 에이전트 작업 가이드

## 목표
증권/계좌 서비스의 4계(채널계/계정계/정보계/대외계)를 분리된 책임으로 구현한다.

## 작업 원칙
- 실무 관점에서 정합성, 장애 대응, 재처리 가능성을 우선한다.
- 계정계는 ACID와 감사 추적을 최우선으로 둔다.
- 채널계는 UX, 재시도, 중복 방지(멱등성)를 기본으로 둔다.
- 정보계는 확정 데이터 기반의 분석/리포팅을 위한 적재 구조를 유지한다.
- 대외계는 비동기 전문 송수신과 재전송/대사 상태를 추적한다.

## 산출물
- backend: Java 21 / Spring Boot / JPA / Querydsl 기반 API 서버
- frontend: React / Next.js 기반 운영 대시보드
- 문서: PLANS.md, TASK.md
