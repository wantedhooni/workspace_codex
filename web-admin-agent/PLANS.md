# 개발 계획

## 1. 프로젝트 기준 정리
- Next.js 16 App Router 기반 프로젝트로 유지한다.
- Next.js 관련 코드를 작성하기 전 `node_modules/next/dist/docs/`의 관련 문서를 확인한다.
- 작업 기록은 `TASK.md`, 실행/운영 방법은 `README.md`에 반영한다.
- 프로젝트 실행 스크립트는 `script/` 아래에서 관리한다.

## 2. API 학습 결과
- API 명세 파일: `api-docs.json`
- OpenAPI 버전: 3.1.0
- API 이름: ADMIN-API
- 기본 서버: `http://localhost:8081`
- 인증 방식: Bearer Token

## 3. 확인된 API 도메인
- 인증: 로그인, 로그아웃, 토큰 갱신, 내 인증 정보 조회
- 관리자: 목록 조회, 생성, 단건 조회, 수정, 삭제
- 계좌: 목록 조회, 생성, 단건 조회, 수정, 삭제
- 계좌 거래: 목록 조회, 생성, 단건 조회, 수정, 삭제

## 4. 우선 구현 방향
- 1차: 인증 상태 관리, 로그인 화면, 토큰 저장/갱신/로그아웃 흐름
- 2차: 관리자 목록/상세/생성/수정/삭제 화면
- 3차: 계좌 및 계좌 거래 화면
- 4차: API 스키마가 비어 있는 계좌/거래 응답 모델 확인 후 타입 보강

## 5. 리스크와 확인 필요 사항
- `account`, `accounttransaction`의 request/response schema가 `object` 또는 `Void` 수준으로만 제공되어 화면 컬럼을 확정할 수 없다.
- 관리자 조회 응답도 현재 명세상 `Void` 또는 비어 있는 page content로 표시되어 실제 응답 예시가 필요하다.
- 데모 계정 정보는 아직 제공되지 않았다.
