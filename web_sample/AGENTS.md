## 작업 지침

- 해당 작업공간 안의 파일만 기준으로 작업하며, 다른 프로젝트를 참고하거나 침범하지 않는다.
- 실무 / 현업 기준에 가깝게 구조, 보안, 예외 처리, 실행 방식을 설계한다.
- 각 작업은 `TASK.md`에 한글로 기록한다.
- class / service / service method 에는 한글 doc 주석을 작성한다.
- 프로젝트 단위 `scripts` 폴더에 `all-start.sh`, `all-stop.sh`, `all-restart.sh`를 둔다.
- `all-start.sh`, `all-restart.sh`는 실행 후 접속 URL과 데모 계정 정보를 출력한다.
- 작업 후 `README.md`를 최신 상태로 유지한다.
