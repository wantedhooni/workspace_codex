# 도메인 용어집

운영 화면과 Dashboard에서 공통으로 사용하는 한글 도메인 용어 정리 문서입니다.

## 1. 계좌/잔고

### Account / 계좌
- 해외 브로커에 개설된 거래 계좌 마스터
- 잔고, 포지션, 증거금, 각종 요청의 기준 단위

### Balance / 잔고
- 계좌와 통화 기준 현재 자금 스냅샷
- 입출금 가능 금액과 유동성 판단의 기준

### Position / 포지션
- 선물/옵션 등 파생상품 종목별 보유 수량과 평균 단가
- 계좌 요약과 리스크 관리의 핵심 기준

### Margin / 증거금
- 거래 유지를 위해 필요한 초기/유지/가용 증거금 정보
- 부족 시 추가 입금 또는 포지션 축소가 필요

### Account Status / 계좌 상태
- 계좌의 운영 가능 상태
- ACTIVE, SUSPENDED, PENDING_CLOSE 등에 따라 요청 처리와 통제가 달라짐

### Available Cash / 가용 현금
- 즉시 요청이나 증거금 대응에 사용할 수 있는 현금 잔액
- 총잔고와 다를 수 있어 운영 판단 시 별도로 봐야 함

## 2. 입출금/환전

### Cash Request / 입출금 요청
- 계좌로 입금하거나 계좌에서 출금하기 위한 운영 요청
- 승인정책, 리스크한도, 4-eyes 통제를 적용

### FX Request / 환전 요청
- 한 통화를 다른 통화로 전환하기 위한 운영 요청
- 브로커 송신 결과에 따라 승인 또는 실패 상태가 기록됨

### 4-eyes Control / 4-eyes 통제
- 요청자와 승인자를 분리하는 내부통제
- 자기 승인 방지를 위한 기본 통제 규칙

### Value Date / 가치일
- 자금이 실제 효력을 가지는 날짜
- 거래일과 다를 수 있어 정산 및 회계 반영 시점 판단에 중요

### Exchange Rate / 환율
- 한 통화를 다른 통화로 환산할 때 적용하는 기준 비율
- 환전 요청의 예상 수취금액과 검토 기준이 됨

### FX Quote / 환전 예상금액
- 기준 환율을 적용해 현재 요청 금액이 상대 통화로 얼마인지 계산한 값
- 실제 체결 금액과는 차이가 날 수 있어 참고값으로 사용

## 3. 주문/체결/정산

### Order / 주문
- 거래소나 브로커에 보내는 매수/매도 지시
- 수량, 가격, 계좌, 상품 정보가 포함됨

### Execution / 체결
- 주문이 실제 시장에서 성사된 결과
- 체결 수량과 단가가 포지션과 정산의 기준이 됨

### Settlement / 정산
- 거래 결과를 현금, 포지션, 회계에 반영하는 후속 처리
- 일일정산과 최종결제 관점 모두 포함

### Product / 상품
- 거래소에 상장된 선물, 옵션, 주식 같은 거래 대상
- 상품별로 거래시간, 증거금, 정산 방식이 다름

### Contract / 종목/계약
- 만기와 규격이 확정된 실제 거래 단위
- 같은 상품 안에서도 월물별로 다른 계약이 존재

### Trading Day / 거래일
- 거래소 달력 기준으로 거래를 인식하는 일자
- 국내 영업일과 달라 배치 기준일 산정에 중요

### Mark to Market / 일일정산평가
- 파생상품을 당일 정산가격으로 재평가하는 절차
- 손익과 증거금이 현금에 반영되는 핵심 운영 개념

## 4. 주식/회계

### Stock Purchase / 주식 매수
- 주식 매수 거래 원본 이벤트
- 거래일, 결제일, 수량, 단가, 수수료를 저장

### Stock Position / 주식 포지션
- 계좌 + 종목 기준 현재 보유 수량, 평균단가, 총원가 집계
- 누적 매수 시 평균단가가 재계산됨

### Ledger Entry / 원장 엔트리
- 거래별 수량 증감, 금액 증감, 누적 보유량을 남기는 운영 원장
- 매수 1건당 1건 생성

### Journal Entry / 분개
- 회계 차변/대변 라인
- 한 거래에 여러 라인이 묶여 생성될 수 있음

### Portfolio / 포트폴리오
- 계좌 기준 현금 잔고, 주식 보유, 최근 거래를 함께 보는 집계 관점
- 다통화 환경을 고려해 장부원가를 통화별로 나눠서 확인

### Book Cost / 장부원가
- 현재 보유 주식의 총 취득원가
- 실현손익이나 시가평가와는 다른 내부 장부 기준 값

### Average Price / 평균단가
- 누적 매수 또는 체결 결과를 기준으로 계산한 보유 단가
- 포지션 평가와 매도 손익 계산의 기준 값

### AI Stock Recommendation / AI 종목 추천
- 포트폴리오 보유 현황과 운용 조건을 바탕으로 AI가 종목 후보와 주의사항을 제안하는 기능
- 실제 주문 전 검토용 초안이며 투자 자문이나 자동 주문 기능은 아님

## 5. 거래소/브로커

### Exchange / 거래소
- 상품이 상장되고 거래 규정이 정의되는 시장 운영 주체
- 거래시간과 정산 규칙의 기준이 됨

### Broker / 브로커
- 주문 집행, 계좌 유지, 자금 이체를 연결하는 외부 중개기관
- 연계 상태에 따라 운영팀의 수동 대응이 필요할 수 있음

### Broker Interface / 브로커 연계
- 브로커와 주문, 잔고, 포지션, 환전 데이터를 주고받는 시스템 인터페이스
- 장애 시 배치 실패, 데이터 불일치, 수동 재처리 이슈가 발생할 수 있음

### Exchange Rule / 거래소 규정
- 상품 상장, 만기, 거래시간, 정산 방식, 증거금 조건을 정의하는 외부 규정
- 규정 변경 시 시스템 반영과 회귀 테스트가 필요

## 6. 통제/운영

### Approval Policy / 승인정책
- 브로커와 요청 도메인별 승인 임계치 정책
- 고액 요청, 수동심사 기준, same-day 자동심사 여부 등을 관리

### Risk Limit / 리스크 한도
- 단건 또는 일중 누적 요청 한도를 정의하는 통제 정책
- 초과 시 요청 차단 또는 수동심사 전환

### Ops Case / 운영 케이스
- 장애, 통제 위반, 연계 실패 후속조치를 추적하는 예외 관리 단위
- 운영팀이 상태 전이와 담당자 배정을 관리

### Batch Run / 배치 실행
- 정산, 포지션 동기화, 증거금 재계산 등 배치 작업의 실행 결과
- 성공/실패/재시도 여부를 운영 화면에서 모니터링

### Audit Log / 감사 로그
- 로그인, 승인, 정책 변경 같은 주요 행위를 남기는 추적 기록
- 내부감사와 사고 원인 분석의 핵심 자료

### Regulatory Report / 대외 보고
- 감독기관 또는 내부 통제 부서에 제출하는 보고 자료
- 거래, 자금이동, 통제 결과를 설명 가능한 형태로 정리해야 함
