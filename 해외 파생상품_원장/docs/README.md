# Docs Index

해외 파생상품 운영 관리자 MVP의 기능/운영 문서 모음입니다.

## 문서 목록
- `FEATURES.md`: 전체 기능 개요, 역할/권한, 도메인 규칙
- `DOMAIN_TERMS.md`: 한글 도메인 용어집, Dashboard/DB 기준 용어 정의
- `DOMAIN_OVERVIEW.md`: 주요 도메인 모델, 관계, 주식 매수 처리 흐름
- `BACKEND_API.md`: 백엔드 API, 요청/응답 흐름, 워크플로우 규칙
- `FRONTEND_GUIDE.md`: 화면 구성, 공통 UX 규칙, 페이지별 기능
- `RSQL_FILTER.md`: RSQL 필터 문법, 연산자, 엔드포인트별 필드
- 포함 도메인: Accounts, Cash/FX Requests, Stock Purchase/Position/Ledger/Journal, Batch, Audit, Menus, Approval Policies, Risk Limits, Ops Cases

## 대상 독자
- 운영/기획: 어떤 기능이 현재 구현되어 있는지 확인
- 개발자: API, 화면 동작, 검색/필터 규칙 확인
- QA: 권한, 워크플로우, 상태 전이 검증 포인트 확인
